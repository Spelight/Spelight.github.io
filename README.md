## About Me / 关于我

I am Dxir. I turn scattered interests, data, and practice into things people can open, use, verify, and keep exploring: Windows automation, local analytics, game tooling, and lightweight web products.

我是 Dxir。我喜欢把零散的兴趣、数据与实践，做成别人可以真正进入、使用、验证并继续探索的东西：Windows 自动化、本地数据分析、游戏工具和轻量 Web 产品。

## Overview / 项目概览

This repository hosts my personal static website on GitHub Pages. It presents projects, writing, community practice, and public-facing experiments in a cleaner narrative than a raw repository list.

这个仓库托管我的 GitHub Pages 个人静态网站，用更清晰的叙事展示项目、文字、社群实践和公开实验，而不是只把访客丢给一串仓库列表。

## Notes / 说明

This site is intentionally lightweight. It is meant to stay easy to edit, easy to deploy, and close to the public identity shown by the rest of my GitHub profile.

这个站点刻意保持轻量：方便修改、方便部署，并和 GitHub 主页里的公开身份保持一致。
